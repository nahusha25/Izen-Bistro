# Izensphere Stay and Dine

**Izensphere Stay and Dine** is an independent, complete Hotel PMS, Restaurant POS, Kitchen Display System, Room & Table Management, Reservations, Folios, and GST Billing system built on the Frappe Framework and ERPNext.

## Features
- **Hotel Operations:** Multi-property management, Room Types, Rooms, Blocks, Sellable Units, Rate Plans, Guardrails.
- **Front Desk:** Visual Tape Chart, Today Command Center, Reservation 360, Guest CRM, Check-in / Check-out workflows.
- **Billing & Folios:** Multi-folio matrix, split billing, credit notes, city ledger accounts, automated nightly audit.
- **Restaurant POS & KDS:** Touch-friendly POS, visual table layouts, kitchen order ticketing (KOT), real-time kitchen display.
- **Event & Banquet Management:** Venue bookings, BEO generation, function diaries, menu builders, milestone billing.
- **Housekeeping & Engineering:** Attendant mobile portal, inspection checklists, maintenance tickets, lost & found.
- **AI & Automation:** Model Context Protocol (MCP) server integration, automated pre-arrival communications, automated night audits.
